Variables Ultra | Rebind, Import & Export Variables

English | 中文 below

Variables Ultra is a free plugin for working with Figma variables. Every feature is free, with no account or sign-in.
Everything runs inside Figma, and nothing is uploaded.

Rebind variables
Use whole collections as themes. Pick a source and a target collection, and every layer in your selection, the
current page or all pages is rebound to the target's variables with the same names. Works with solid and gradient
fills, strokes, effects, layout grids, layer properties and text, and with collections from team libraries. Anything
that can't be rebound is listed in the Conflict View.

Import and export
Export every collection and variable in a file, aliases included, to a JSON file. Import it into another file and pick
the collections you need; the collections they depend on come along automatically.

Material 3 templates
Pick a seed color to generate a Material 3 color scheme with Dark, Light, Light Medium Contrast and Light High Contrast
modes. Create a new collection, or update or merge into an existing one.

A better variables view
All collections side by side, quick single and multi-selection, easier aliasing, and batch editing of scopes.

Full guide with screenshots: https://github.com/variables-ultra/variables_ultra_doc

Variables Ultra 是一款免费的 Figma 变量管理插件。所有功能免费，不需要注册或登录；所有操作都在 Figma 里完成，不会上传任何数据。

变量重绑定
把整个变量集当作主题来用。选好源变量集和目标变量集，选中的图层、当前页或所有页里的图层，都会按变量名换绑到目标变量集里的同名变量。
支持纯色和渐变填充、描边、效果、布局网格、图层属性和文本，也支持团队库里的变量集。无法重绑定的内容会列在 Conflict View 里。

导入和导出
把文件里所有的变量集和变量（包括别名关系）导出成一个 JSON 文件，再导入到别的文件里，按需勾选变量集，依赖的变量集会自动带上。

Material 3 模板
选一个种子色，生成包含 Dark、Light、Light Medium Contrast、Light High Contrast 四个 mode 的 Material 3 配色。
可以新建变量集，也可以更新或合并到已有的变量集。

更好用的变量视图
所有变量集并排显示，单选、多选更顺手，设置别名更方便，还能批量修改作用范围。
